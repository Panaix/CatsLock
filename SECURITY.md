# Безопасность и конфиденциальность

## Сообщить об уязвимости

Пожалуйста, не публикуйте непроверенную уязвимость в открытом Issue. Используйте
[приватное сообщение об уязвимости на GitHub](https://github.com/Panaix/CatsLock/security/advisories/new).
Укажите затронутую версию, шаги для воспроизведения и возможное влияние.
Не прикладывайте личные данные или реальные записи нажатий клавиатуры.

Поддерживаются актуальный релиз и последняя версия из ветки `main`. Сроки
исправления зависят от серьёзности и наличия сопровождающего.

## Обработка данных

- Для блокировки и обнаружения быстрых нажатий приложение использует системный
  Accessibility API и перехват событий клавиатуры macOS.
- Для обнаружения быстрых нажатий в памяти процесса временно хранятся коды
  клавиш и время их поступления. Текст, вводимый пользователем, не собирается и
  не записывается приложением.
- История нажатий не сохраняется на диск и не передаётся по сети. Сетевой
  обмен, аналитика и телеметрия приложением не реализованы.
- Настройки чувствительности и выбранный язык хранятся локально в
  `UserDefaults`.
- При разрешении пользователя приложение может показывать уведомления через
  системную службу уведомлений macOS.

Разрешение Accessibility необходимо для обработки событий клавиатуры и
временного подавления нажатий при активной блокировке. CatsLock не является
защитой от вредоносного ПО и не заменяет механизмы безопасности macOS.

## Проверки релиза

Pull request и публикация версии проверяются GitHub Actions: выполняется
проверка Swift и сборка Universal Binary/DMG для Intel и Apple silicon.
Подпись Developer ID и нотарификация Apple пока не настроены; скачанный DMG
может вызвать предупреждение Gatekeeper.
