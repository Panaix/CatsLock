# CatsLock

CatsLock — приложение для macOS, которое временно блокирует клавиатуру и
помогает обнаруживать случайные быстрые нажатия.

Интерфейс доступен на русском, английском, немецком, испанском, французском,
китайском и японском языках.

## Установка

Скачайте `CatsLock-Installer.dmg` из раздела **Releases** на GitHub, откройте
образ и перетащите CatsLock в папку **Applications**. При первом запуске
macOS попросит разрешить приложению доступ в разделе **Системные настройки →
Конфиденциальность и безопасность → Универсальный доступ**. Это разрешение
необходимо для перехвата и временной блокировки нажатий клавиатуры.

## Сборка

Требуются macOS и Swift, установленный вместе с Xcode Command Line Tools.

```sh
xcode-select --install
./scripts/build-release.sh
```

Скрипт создаёт `build/CatsLock.app` и `build/CatsLock-Installer.dmg`. По
умолчанию приложение подписывается ad hoc, поэтому macOS может показать
предупреждение при запуске. Для распространения без такого предупреждения
нужны сертификат **Developer ID Application** и нотарификация Apple. Укажите
сертификат через переменную окружения `CODESIGN_IDENTITY` при запуске скрипта.

## Горячие клавиши

- `Control + Option + L` — переключить блокировку.
- `Control + Option + Escape` — аварийная разблокировка.
