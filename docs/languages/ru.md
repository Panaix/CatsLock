# CatsLock — русский

[Выбрать другой язык](../../README.md)

CatsLock — приложение для macOS, которое временно блокирует клавиатуру и
обнаруживает случайные быстрые нажатия. Интерфейс приложения доступен на
русском, английском, немецком, испанском, французском, китайском и японском.

## Требования

- macOS 13 или новее.
- Mac с процессором Intel или Apple silicon.

## Установка

Скачайте [CatsLock-Installer.dmg](https://github.com/Panaix/CatsLock/releases/latest),
откройте образ и перетащите приложение CatsLock в папку Applications. При
первом запуске разрешите CatsLock доступ в **Системные настройки → Конфиденциальность
и безопасность → Универсальный доступ**. Это разрешение необходимо для
обработки клавиш и временного подавления нажатий при блокировке.

Текущий установщик подписан ad hoc и не нотарифицирован Apple. macOS может
показать предупреждение Gatekeeper.

## Конфиденциальность и безопасность

CatsLock обрабатывает события клавиатуры локально. Для обнаружения быстрых
нажатий коды клавиш и время их поступления временно хранятся в памяти процесса.
Приложение не записывает вводимый текст, не сохраняет историю на диск и не
передаёт события клавиатуры по сети. Настройки хранятся локально в
`UserDefaults`; уведомления доставляет macOS. Аналитики и телеметрии нет.

Для сообщения об уязвимости используйте
[приватное сообщение на GitHub](https://github.com/Panaix/CatsLock/security/advisories/new),
а не публичный Issue. Не прикладывайте пароли, личные данные или содержимое
клавиатурного ввода. Подробнее — в [политике безопасности](../../SECURITY.md).

## Сборка из исходников

Установите Xcode Command Line Tools, затем выполните:

```sh
xcode-select --install
./scripts/build-release.sh
```

Скрипт создаёт Universal Binary и установщик в `build/`. Версию и номер сборки
можно задать через `VERSION` и `BUILD_NUMBER`. Подпись Developer ID и
нотарификация требуют сертификата Apple Developer и пока не настроены.

## Горячие клавиши

- `Control + Option + L` — переключить блокировку.
- `Control + Option + Escape` — аварийная разблокировка.
